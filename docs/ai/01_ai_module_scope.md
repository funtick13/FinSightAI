# 01. Область применения AI‑модуля

## Назначение

AI‑модуль FinSight AI — это отдельный микросервис на Python, который отвечает **исключительно за аналитическую обработку финансовых данных**. После того как backend получил и распарсил выписки, сохранил транзакции и подготовил список операций, он вызывает AI‑сервис. Задача AI‑модуля — рассчитать доходы и расходы, сгруппировать расходы по категориям, выявить финансовые паттерны и сформировать инсайты и рекомендации для пользователя.

## Область ответственности

AI‑модуль **выполняет**:

- Принимает запрос `AnalysisRequest` со списком транзакций, периодом, банком, идентификаторами выписок и идентификатором пользователя.
- Валидирует входные данные и проверяет, что операции корректны и непусты.
- Считает суммарные доходы, расходы и баланс по заданному периоду.
- Группирует расходы по категориям, вычисляет долю каждой категории и находит топ‑3 категорий расходов.
- Определяет финансовое состояние месяца (rule‑based предиктор) и обнаруживает паттерны расходов.
- Генерирует краткие аналитические инсайты и персонализированные рекомендации и возвращает их backend‑у для отображения в приложении.

## Что не входит в ответственность

AI‑сервис **не** занимается:

- Регистрацией и авторизацией пользователей, загрузкой PDF и обработкой исходных файлов; эти функции реализует backend Spring Boot.
- Парсингом выписок и сохранением операций — backend готовит список транзакций и передаёт его в AI‑модуль.
- Хранением результатов анализа — сохранение агрегированных данных, инсайтов и рекомендаций обеспечивает backend и база данных PostgreSQL.
- Отрисовкой графиков и пользовательским интерфейсом; эту часть обеспечивает мобильное приложение Flutter.
- Обучением или развертыванием моделей машинного обучения. В первой версии используются rule‑based правила; поддержка ML предусмотрена как развитие системы.

## Место модуля в системе

FinSight AI состоит из трёх основных компонентов: мобильного приложения Flutter, backend‑сервера Spring Boot и AI‑сервиса Python. Мобильное приложение отображает интерфейс, вызывает backend для загрузки выписок и просмотра аналитики. Backend хранит пользователей, выписки и транзакции, выполняет парсинг документов и вызывает AI‑сервис для расчётов. AI‑сервис предоставляет REST API и возвращает результаты анализа в виде структурированного ответа, после чего backend сохраняет их и отправляет в мобильное приложение.
