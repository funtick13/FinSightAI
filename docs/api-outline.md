# Структура API

В этом документе приведён набросок структуры API для проекта
**FinSight AI**.  Реальные определения эндпоинтов будут реализованы в
соответствующих кодовых базах серверной части и AI‑сервиса и
уточняться по мере развития проекта.  Задача данного наброска — дать
отправную точку для проектирования адресов, параметров и структур
ответов.

## API серверной части (Spring Boot)

Все эндпоинты по умолчанию начинаются с `/api`, если не указано иное.
Для передачи данных используется JSON.  Аутентификация должна
обеспечиваться JWT или сессионными куки, где это необходимо.

### Аутентификация

| Метод | Эндпоинт                  | Описание                                                                         |
|------:|---------------------------|----------------------------------------------------------------------------------|
| POST  | `/auth/register`          | Регистрация нового пользователя. Принимает email, пароль и (опционально) имя. Возвращает токен подтверждения. |
| POST  | `/auth/login`             | Аутентификация пользователя. Принимает email и пароль. Возвращает JWT.          |
| POST  | `/auth/confirm`           | Подтверждение email пользователя с помощью токена из письма.                     |
| POST  | `/auth/forgot-password`   | Инициация сброса пароля. Отправляет письмо со ссылкой для сброса.               |
| POST  | `/auth/reset-password`    | Завершение сброса пароля с использованием токена и нового пароля.               |

### Управление выписками

| Метод | Эндпоинт                   | Описание                                                                          |
|------:|----------------------------|-----------------------------------------------------------------------------------|
| POST  | `/statements/upload`       | Загрузка PDF‑выписки. Принимает multipart/form‑data с файлом, банком и месяцем. Возвращает ID выписки. |
| GET   | `/statements`              | Список всех выписок текущего пользователя. Поддерживает пагинацию.               |
| GET   | `/statements/{id}`         | Получение метаданных конкретной выписки.                                         |
| DELETE| `/statements/{id}`         | Удаление выписки и связанных операций.                                           |

### Операции

| Метод | Эндпоинт                | Описание                                                                       |
|------:|-------------------------|--------------------------------------------------------------------------------|
| GET   | `/operations`           | Получение постраничного списка операций за указанный месяц.                    |
| GET   | `/operations/{id}`      | Получение одной операции.                                                      |

### Аналитика

| Метод | Эндпоинт                | Описание                                                                 |
|------:|-------------------------|--------------------------------------------------------------------------|
| GET   | `/analytics/summary`    | Получить общие доходы, расходы и разбивку по категориям за выбранный месяц. |
| GET   | `/analytics/history`    | Список сводной аналитики за прошлые месяцы.                                 |
| GET   | `/analytics/compare`    | Сравнение двух и более месяцев.                                            |

### Рекомендации

| Метод | Эндпоинт               | Описание                                                     |
|------:|------------------------|--------------------------------------------------------------|
| GET   | `/recommendations`     | Получить рекомендации на основе правил за выбранный период. |

### Профиль

| Метод | Эндпоинт       | Описание                                         |
|------:|----------------|--------------------------------------------------|
| GET   | `/profile/me`  | Получить информацию о текущем пользователе.      |
| PUT   | `/profile/me`  | Обновить информацию о текущем пользователе.      |

## API AI‑сервиса (FastAPI)

### Проверка состояния

| Метод | Эндпоинт   | Описание                                      |
|------:|------------|-----------------------------------------------|
| GET   | `/health`  | Эндпоинт для проверки работоспособности.       |

### Анализ данных

| Метод | Эндпоинт     | Описание                                                                                |
|------:|--------------|-----------------------------------------------------------------------------------------|
| POST  | `/analyze`   | Принимает JSON с списком операций и возвращает агрегированные результаты и инсайты.      |

#### Схема запроса

```json
{
  "operations": [
    {
      "date": "YYYY-MM-DD",
      "amount": 123.45,
      "description": "Описание платежа",
      "category": "Продукты"
    }
  ]
}
```

#### Схема ответа

```json
{
  "income_total": 1000.00,
  "expense_total": 800.00,
  "category_totals": {
    "Продукты": 200.00,
    "Развлечения": 300.00
  },
  "insights": [
    {
      "title": "Топ категория расходов",
      "description": "Ваша самая большая статья расходов: Развлечения"
    },
    {
      "title": "Доходы vs. расходы",
      "description": "Вы заработали 1000.00 и потратили 800.00 за период."
    }
  ]
}
```
