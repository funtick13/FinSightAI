# «Управление выписками» — Требования к интеграции

## Назначение
Цель интеграции — предоставить базовую функциональность по загрузке PDF‑выписок, их хранению и удалению без выполнения парсинга и аналитики. Реализованная подсистема должна быть готова к дальнейшему расширению: в следующих этапах к ней будут подключены разбор PDF‑файлов, извлечение операций и анализ с помощью AI‑модуля.

На этом этапе подсистема работает только для авторизованных пользователей и поддерживает один банк (Сбербанк), соответствуя ограничениям MVP.

## Область ответственности

Подсистема управления выписками занимается только файлами и их метаданными. Она не выполняет:

- распознавание и парсинг PDF‑файлов;
- нормализацию операций;
- категоризацию транзакций;
- вызов AI‑сервиса;
- хранение аналитических данных.

Эти функции появятся на следующих стадиях. Подсистема должна, однако, обеспечить основу для их дальнейшего подключения (например, предусмотреть хранение статуса обработки).

## Модель данных

Сущность `Statement` описывает одну банковскую выписку. Каждая запись связана с пользователем и содержит следующую информацию:

| Поле | Тип | Описание |
|---|---|---|
| `id` | UUID | Уникальный идентификатор выписки |
| `userId` | UUID | Идентификатор владельца выписки |
| `bank` | `BankType` | Банк, от которого получена выписка (MVP — `SBERBANK`) |
| `period` | string (YYYY-MM) | Анализируемый месяц |
| `originalFileName` | string | Имя файла, указанное пользователем |
| `storedFileName` | string | Уникальное имя файла на диске |
| `filePath` | string | Абсолютный путь к файлу на сервере |
| `contentType` | string | Тип содержимого (всегда `application/pdf`) |
| `fileSize` | number | Размер файла в байтах |
| `status` | `StatementStatus` | Статус обработки |
| `uploadedAt` | datetime | Время загрузки файла |
| `processedAt` | datetime или null | Время завершения обработки |
| `errorMessage` | string или null | Описание ошибки |

## Перечисления

```text
SBERBANK
```

```text
UPLOADED
PROCESSING
PROCESSED
FAILED
```

## REST API

### POST `/api/statements`

Загрузка PDF‑выписки.

Параметры:

- `file`
- `bank`
- `period`

### GET `/api/statements`

Получение списка выписок пользователя.

### GET `/api/statements/{id}`

Получение информации о конкретной выписке.

### DELETE `/api/statements/{id}`

Удаление выписки и связанного файла.

## Ограничения

- поддерживаются только PDF‑файлы;
- максимальный размер файла ограничен;
- поддерживается только `SBERBANK`;
- все endpoints требуют JWT‑авторизации;
- пользователь не может получать доступ к чужим выпискам.

## Ожидаемый результат

После завершения этапа должны быть реализованы:

1. Загрузка PDF‑выписок.
2. Хранение файлов и метаданных.
3. Управление выписками пользователя.
4. Базовые статусы обработки.
5. Готовность backend к следующему этапу — парсингу PDF и интеграции с AI‑сервисом.
